# Lazy Mushroom — releases

Installers for Lazy Mushroom, a personal Windows app for the work day.

This repository holds **only** the finished installers and the small
`latest.json` file the app reads to find updates. There is no code and no
user data here.

**To install:** open [Releases](../../releases/latest), download the
`_x64-setup.exe` file and run it. After that, the app updates itself.
